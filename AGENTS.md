# Правила для LLM-разработчика

Этот репозиторий: личное портфолио Дани (Danylo Chuprov, продуктовый дизайнер). Ветка `v2` строится с нуля по [docs/SPEC.md](docs/SPEC.md). Прочитай спеку целиком до первой строки кода.

## Как устроена работа

- Порядок: сначала Даня делает дизайн страниц в Figma, потом вёрстка по нему. Не начинай код страницы, пока её макет в Figma не утверждён Даней. Для визуала (цвета, размеры, отступы) макет Figma главнее скриншотов Рейчел и токенов из спеки; спека задаёт структуру, поведение и стек.
- Контент (тексты, картинки, видео) готовится в отдельном проекте Claude и приходит коммитами в `content/`. Ты пишешь код и схемы, но не тексты.
- Не придумывай тексты, цифры, метрики, названия компаний и проектов. Если контента нет, ставь заглушку `[нужны данные: что именно]` и иди дальше.
- Если для кода нужен новый тип блока или поле, добавь его в `schema/` и опиши в `content/README.md`, чтобы контент-сторона знала про него.
- Референс дизайна: `docs/reference/`. 1 px скриншота = 1 CSS px при ширине окна 1736.

## Git

- Работай в `v2` или в ветках от неё. В `main` не пушить и не мержить без явного «ок» Дани.
- `main` и ветка `legacy-v0.1` хранят старый сайт. Не удалять и не переписывать их историю.
- Не коммитить секреты. Ключи только через `wrangler secret put`.

## Технические рамки

- Хостинг только Cloudflare Workers и бесплатные сервисы Cloudflare (Workers AI, D1, R2, Durable Objects, Turnstile, Access, Web Analytics).
- Три языка: ru, uk, en. Любая новая строка интерфейса сразу в трёх файлах `src/i18n/ui.*.json`.
- Все цвета, размеры шрифтов и отступы только через токены из `src/styles/tokens.css`.
- Уважать `prefers-reduced-motion` и работу с клавиатуры в каждом интерактивном компоненте.

## Язык

Комментарии в коде и коммиты на английском. Документы для Дани (README, спека, отчёты) на русском.
