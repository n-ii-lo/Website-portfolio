# Портфолио: фронтенд (v0.1)

Astro, статическая сборка, без внешних сервисов: шрифты лежат в пакетах `@fontsource`, ничего не грузится с чужих доменов.

## Запуск

```bash
npm install
npm run dev       # http://localhost:4321 → редирект на /ru/
npm run build     # готовый сайт в dist/
npm run preview   # посмотреть dist/ локально
```

## Страницы

| Адрес | Что |
|---|---|
| `/` | Редирект на язык браузера (ru, uk, en), без JS сразу на `/ru/` |
| `/{lang}/` | Главная: hero-фраза, опыт, сетка кейсов (первый кейс широкий) |
| `/{lang}/work/{slug}/` | Кейс в раскладке Rachel Chen: липкое оглавление, eyebrow, H1, обложка, строка «роль, сроки, команда, навыки», разделы из блоков, «следующий кейс» |
| `/{lang}/about/` | Обо мне: фраза, текст, опыт, контакты |
| `/404.html` | Не найдено |

## Контент

Данные лежат в `src/data/` и повторяют документы админки один в один:

- `src/data/site.json` — документ `site/settings`
- `src/data/projects/<id>.json` — документ `projects/<id>`, имя файла становится адресом кейса

Сейчас там выгрузка из админки на 2026-10-09. Чтобы обновить кейс, скопируйте JSON во вкладке «JSON» админки и замените файл.

Текстовые поля хранятся как `{ru, uk, en}`. Если перевода нет, показывается русский текст (с пунктирным подчёркиванием, пока включены пометки).

Поддержаны все 13 блоков админки: heading, text, label, figure, flows, stats, columns, quote, exploration, options, beforeAfter, goals, divider. Компонент: `src/components/Block.astro`.

### Картинки

Админка хранит картинки как `{ "id": "…" }` во внутреннем хранилище, на статический сайт их пока не выгрузить. Сайт понимает такую форму:

```json
"cover": { "src": "/images/beeezo-ds/cover.jpg", "alt": "…" }
```

Файл кладётся в `public/images/…`. Видео `.mp4` и `.webm` играют сами, без звука, по кругу. Пока картинки нет, на её месте плашка с текстом «что показать» из админки.

Поле `about` в `site.json` (текст для «Обо мне») в админке пока нет, сайт его уже читает.

## Переключатели

`src/site.config.ts`:

- `showDrafts` — показывать кейсы с `published: false`. Сейчас все четыре кейса черновики, поэтому включено.
- `showMarkers` — подсвечивать пометки `[нужны данные …]`, `[проверьте …]` и плашки «что показать». Перед публикацией выключить: пометки исчезнут из текста.

## Цвета

Все цвета в `src/styles/global.css`, пять токенов:

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#FAFAF8` | Фон страницы |
| `--bg-alt` | `#EFEFEB` | Плашки: фигуры, обложки, заглушки |
| `--text` | `#17191E` | Заголовки и основной текст |
| `--muted` | `#6C7079` | Абзацы, метки, второстепенное |
| `--accent` | `#2B50C8` | Акцент: курсив в hero, цифры, выбранный вариант, активный пункт |

Линии и мягкий акцентный фон считаются из них через `color-mix`, отдельных цветов нет. Поле `accent` кейса перекрашивает `--accent` на его странице и в карточке.

Шрифты: Source Serif 4 (заголовки), IBM Plex Sans (текст, жирный 700), IBM Plex Mono (метки). У всех есть кириллица. Все текстовые стили с размерами и межстрочными собраны в [type-styles.md](type-styles.md).

## Мобильная версия

- Шапка на телефоне в две строки: имя и роль, ниже меню и языки. Все ссылки и кнопки не меньше 44×44 px.
- В кейсе на ширине до 900 px вместо левого оглавления появляется липкая строка с текущим разделом и номером (`3/7`). По тапу открывается список разделов, под строкой идёт полоса прогресса чтения.
- Фигуры на телефоне растянуты от края до края, чтобы скриншотам досталась вся ширина. Высокие скриншоты экранов во «Флоу» сохраняют свои пропорции и не обрезаются.
- Тап по картинке открывает её на весь экран, поддерживается зум пальцами. Закрыть можно тапом или клавишей Esc.
- Проверено на ширинах 320, 360, 390, 768 px и в альбомной ориентации 844×390: горизонтального скролла нет, шрифт не мельче 12 px. Серый текст проходит контраст WCAG AA на обоих фонах.

## Структура

```
src/
  data/                 контент из админки
  i18n/ui.ts            тексты интерфейса на трёх языках, смена языка в адресе
  lib/content.ts        загрузка JSON, переводы, разметка **жирный** / *курсив* / [пометки]
  components/           Block, Media, CaseCard
  layouts/Base.astro    шапка, меню, языки, футер, hreflang
  pages/                страницы
  styles/global.css     токены и база
```

Перед деплоем поменяйте `site` в `astro.config.mjs` на свой домен.
