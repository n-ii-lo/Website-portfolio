# Контент

Источник правды для всех текстов, картинок и видео сайта. Наполняется из проекта Claude, разработчик тексты не правит. Полная схема в [docs/SPEC.md, раздел 9](../docs/SPEC.md#9-контент).

## Структура (целевая)

```
content/
  site/settings.json     имя на 3 языках, контакты, ссылка на резюме, флаги features, имя ассистента
  site/theme.json        цвета, если отличаются от токенов по умолчанию
  site/moderation.json   стоп-слова для заметок
  ru/ uk/ en/
    home.json            hero, «Сейчас» / «Раньше»
    about.json           абзацы, опыт, группы фото
    gallery.json         теги и элементы галереи
    assistant.json       подсказки, факты, FAQ для ассистента
    cases/<slug>.json    кейс: мета + главы из блоков
  media/                 картинки до 1 MB; крупное и видео в R2
  _import-v0.1/          выгрузка из админки v0.1 (2026-10-09), только для миграции
```

## Правила

- Переводимые тексты в папке языка. Сначала пишем `ru`, переводы `uk` и `en` после того, как Даня скажет «контент ок».
- Метрики не выдумываем. Если данных нет: `[нужны данные: …]`. Кейс с такой пометкой не опубликуется в `main`.
- Блок с `"private": true` не попадёт ни на сайт, ни в базу ассистента. Так помечаем то, что под NDA.
- У каждой картинки и видео обязателен `alt`.
